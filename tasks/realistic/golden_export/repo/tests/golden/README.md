# Certified golden hash

`bank_export.sha256` is the SHA-256 of the sample export that the bank's onboarding team certified (cert ref
BK-CERT-4471, format v2). The bank only accepts uploads in a format it has certified.

Do not regenerate or edit this hash locally. When the format changes, Treasury submits the new sample file through
the bank's certification portal and commits the hash the bank sends back.
